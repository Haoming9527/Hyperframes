Short pitch · Tech Lead

Give Devin a way to make video.

HyperFrames turns video into HTML + a local render. We already have Devin — this is the missing playbook.

Internal · R&D AI Innovation

1 · What it is

HyperFrames = HTML → MP4

An agent writes a web page with timing. The CLI renders it to video.

Like code

Diff, review, retry — same as a normal PR.

Not magic video AI

Structure and polish stay controllable. Brand stays ours.

2 · Why it matters

Gen video is fast. Editable video is hard.

  • Model MP4s are hard to change and hard to version
  • Editors (After Effects) don’t fit an agent workflow
  • Banks need inspectable, local-friendly pipelines

HyperFrames makes video something Devin can own in git.

3 · How we run it

Devin is already here. Point it at HyperFrames.

  • No new agent — use OCBC Devin
  • Add .skills + CLI in a research repo
  • Same review — PR with HTML + MP4
Task Devin → follow .skills → edit HTML → local render → human reviews PR

4 · Network

Core loop can stay local.

Needs internet

Install / update skills once. Optional cloud render or TTS.

Works offline after that

Write HTML, check, preview, render with Node + Chrome + FFmpeg.

Skills are markdown on disk. Devin reads them — no HeyGen API required to author or render locally.

5 · Ask

2-week spike. One clear decision after.

  • Point Devin at HyperFrames: one captioned clip + one short explainer
  • Local render only — score time, quality, how much human fix-up
  • Then: adopt for prototypes · park · or compare Remotion
